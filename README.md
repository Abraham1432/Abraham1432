## What I’m building right now

I spend most of my time designing and shipping **Small Language Model (SLM) infrastructure** so that banks, law firms and compliance teams can run AI *without sending a single token* to public APIs.

- 🐳 **Zyrabit SLM** — Docker-first local AI stack  
  SLM engine, RAG, Zero-Trust PII redaction and observability in one image.  
  Runs fully inside your perimeter, no external network calls.

- 🧠 **Cortex / Gravity / Mobility**  
  - Cortex — on-device reasoning core.
  - Gravity — The UI layer: chat + console to interact with your SLM.
  - Mobility — Naval & Air.

- 🧩 **Blueprints for regulated environments**  
  Mac mini edge nodes, on‑prem RTX workstations, air‑gapped VPC enclaves, and clinical / financial deployments built on the same SLM stack.
